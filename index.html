Cryptographic Bill of Materials

Fuse. Normalize. Understand.

CBOMFuse reconciles cryptographic inventories from multiple analysis tools into a unified, deterministic, and auditable Cryptographic Bill of Materials.

Get Started View on GitHub
The Problem

Cryptographic inventories don't always agree.

Different CBOM generators may identify the same cryptographic asset using different names, schemas, parameter representations, or levels of detail.

Capabilities

Built for reliable CBOM reconciliation.

N

Normalization

Normalize algorithm names, parameter sets, key sizes, curves, modes, and other cryptographic metadata.

M

Semantic Matching

Identify when differently represented cryptographic assets refer to the same underlying primitive.

F

CBOM Fusion

Combine multiple CBOMs into a unified CycloneDX-compatible cryptographic inventory.

A

Auditable Decisions

Every transformation and matching decision can be associated with a versioned rule.

R

Risk & Confidence

Assign confidence and risk information to reconciled cryptographic assets.

P

PQC Awareness

Support analysis of classical and post-quantum cryptographic algorithms and parameter sets.
